# Security policy

Please do not open a public issue containing access tokens, private Tailscale hostnames, Codex task IDs, prompts, terminal logs, screenshots, or local paths.

For a suspected vulnerability, create a private GitHub security advisory for this repository. Include the minimum reproduction details and redact personal data. Rotate any exposed application token or Tailscale credential immediately.

The supported version is the latest release on the default branch. This personal tool is designed for loopback binding and private-tailnet access only. Public hosting is outside its security model.
